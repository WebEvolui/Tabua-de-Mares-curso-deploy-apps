### Para Executar no Linux basta dar permissão de execução (se não tiver já) e depois clicar duas vezes
Baixe o arquivo *.AppImage*

```Bash
#!/bin/bash
sudo apt install libfuse2 -y
chmod +x Tabua_de_Mares-x86_64.AppImage
echo "Pronto! Agora é só abrir o arquivo da Tábua de Marés."
```
